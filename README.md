# ガソリンカード 集計・按分・費用振替CSV作成ツール

毎月の利用明細PDF・管理台帳・給与按分資料から、照合 → 集計 → 按分 → 費用振替CSV作成までを自動で行います。
担当者は **エラーとして表示された箇所だけ** を確認・修正します。

- 仕様（データ項目・按分ルール・エラーコード・セキュリティ）: [docs/仕様書.md](docs/仕様書.md)

## 初回セットアップ

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
```

AI読取補助を使う場合は、プロジェクト直下の `.env` に Claude API キーを書きます
（使わない場合は空欄のままでOK。AIなしでも動きます）。書き換えたら画面を再起動してください。

```
ANTHROPIC_API_KEY=sk-ant-...
```

`.env` は秘密情報なので人に渡さないでください（`.gitignore` で共有対象外にしています）。

## 入力ファイル

`入力ファイル見本/` にあります。作り直すときは `.\.venv\Scripts\python tools\make_samples.py`。

| フォルダ | 内容 |
|---|---|
| `ダミーデータ_2026-10` | 架空データ（**エラー入り**）。エラー修正・再集計の練習用 |
| `ダミーデータ_2026-11` | 架空データ（**エラーなし**）。そのままCSVまで出せる |
| `テンプレート` | 実データ用の空の管理台帳・給与按分資料（記入ルールのシート付き） |

## ログインと役割

初めて画面を開いたときだけ「管理者アカウントの作成」画面が出ます。ここで最初の管理者を作ってください。
以降はログインが必要です。ユーザーの追加・設定の変更はすべて「管理」画面で行い、ファイルを触る必要はありません。

| 役割 | できること |
|---|---|
| 管理者 | すべて ＋ 管理画面（ユーザー追加・無効化・パスワード再発行、設定、操作ログ） |
| 担当者 | 集計・エラー修正・CSV出力・月次推移 |
| 閲覧者 | 月次推移を見るだけ |

- ユーザーを追加すると仮パスワードが表示されます（一度だけ）。本人は初回ログイン時に新しいパスワードを設定します
- パスワードは暗号化（bcrypt）して保存。5回続けて間違えると15分ロック。30分操作がないと自動ログアウト
- 有効な管理者が0人になる操作（最後の管理者の無効化など）はできません
- データは `data/app.db`（SQLite）に保存：ユーザー・設定・操作ログ・実行記録・月ごとの施設別確定金額

## 月次推移（SQLで集計）

エラー0件でCSVを出力できた月は、施設別の確定金額がデータベースにたまり、「月次推移」画面で
月ごとの合計・施設ランキング（構成比）・施設別の推移と前月差を見られます。使っているSQLは画面内で確認できます（[src/reports.py](src/reports.py)）。

## 公開デモ（Streamlit Community Cloud）

架空データだけで触れるデモとして公開できます。**実データは公開環境に置かないでください。**

1. https://share.streamlit.io に GitHub アカウントでログイン →「Create app」
2. リポジトリ・ブランチ `main`・Main file `app.py` を選び、Advanced settings で Python 3.11 を選ぶ
3. Secrets に次を貼り付けて Deploy

```toml
GASCARD_DEMO = "1"
```

デモモードでは：デモ用アカウント（demo_admin / demo_staff / demo_viewer、パスワード demo1234）が自動で作られ、
ファイルのアップロードとAI読取補助は無効、デモ用アカウントは変更・ロックできません。
クラウドのデータは再起動で消えるため、月次推移などは毎回まっさらな状態から始まります。

## 毎月の操作手順

1. **画面を起動**: `start.bat` をダブルクリック（このPCからしか開けない設定で起動）→ ブラウザで http://localhost:8501 が開く
2. **ログイン**し、メニューの「集計」で**対象月を入力**（例 `2026-10`）。「入力ファイルを置く」から3つのファイルをアップロードして「保存する」
   - 利用明細（PDF）／管理台帳（Excel）／給与按分資料（Excel）
   - 直接 `data/input/2026-10/` に置いてもよい（ファイル名は `利用明細_*.pdf`・`管理台帳_*.xlsx`・`給与按分_*.xlsx`）
3. **「▶ 実行（再集計）」** を押す
4. **「エラー確認・修正」タブ**でエラーを1件ずつ確認する
   - 金額の読取エラー → PDF原本を見て金額を入力
   - 台帳にないカード → 利用施設・区分を指定（翌月以降のために管理台帳にも追加する）
   - 按分資料にない・割合が100%でない → 按分先と割合を入力
   - 修正を確定すると自動で再集計される
5. 「要確認」（AIが読んだ行・名義の不一致）は原本と見比べて確認する
6. エラーが0件になり、**「整合性チェック」が一致**したら「出力」タブから3つのファイルをダウンロード
   - `費用振替_YYYYMM.csv` → 会計システムに取り込む
   - `カード別施設別集計_YYYYMM.xlsx` / `エラー一覧_YYYYMM.xlsx` → 保管・回覧用

> エラーが残っている間は費用振替CSVは作られません（誤った金額の取込を防ぐため）。

### コマンドで実行する場合

```powershell
.\.venv\Scripts\python -m src.pipeline --month 2026-10          # AIあり
.\.venv\Scripts\python -m src.pipeline --month 2026-10 --no-ai  # AIなし
```

## 修正した内容を取り消したいとき

「修正履歴」タブで「取消」を押します。修正は `data/corrections/<対象月>.json` に記録されており、
元のPDF・Excelは一切書き換えていません。

## 開発・テスト

```powershell
.\.venv\Scripts\python tools\make_dummy.py --month 2026-10   # 架空のテストデータを作る
.\.venv\Scripts\python -m pytest -q                         # テスト（14件）
```

## フォルダ構成

```
app.py              画面（⑥エラー確認・修正・再集計）
config.yaml         列名・勘定科目・CSV形式・AI設定
src/ledger.py       ① 管理台帳の取込（有効期間で当月の行を選ぶ）
src/pdf_reader.py   ② 利用明細PDFの読取・検算
src/ai_assist.py    ② 読めなかった行のAI読取補助（Claude API）
src/matcher.py      ③ カード番号での照合
src/allocator.py    ④ 按分（最大剰余法）
src/exporter.py     ⑤ CSV・Excel出力
src/pipeline.py     ①〜⑤の実行・整合性チェック・修正ファイル管理
tools/make_dummy.py ダミーデータ作成
tests/              自動テスト
data/               入力・出力・修正・ログ（個人情報を含むため共有しない）
```
